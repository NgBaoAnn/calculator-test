# TC-DIV-003: Chia cho kết quả thập phân hữu hạn

## Requirement ID
FR-CALC-02

## Module / Test type / Technique
Module 2 - Division / Functional / Equivalence Partitioning

## Preconditions
- Người dùng đã mở trang: https://testsheepnz.github.io/BasicCalculator.html
- Chạy riêng test case trên từng Build từ 1 đến 9; tải lại trang trước mỗi lượt.

## Test data
Build áp dụng: Build 1–9; chạy riêng từng Build.

| First number | 5 |
| Second number | 2 |
| Operation | Divide |

## Test steps
1. Chọn Build đang kiểm thử.
2. Nhập "5" vào trường First number và "2" vào trường Second number.
3. Chọn Operation là "Divide".
4. Bấm "Calculate".

## Expected result
Answer hiển thị chính xác "2.5". Không có thông báo lỗi.

## Status / Related bugs
Not Run / None
