# TC-DIV-003: Chia cho kết quả thập phân hữu hạn

## Requirement ID
FR-CALC-02

## Module / Test type / Technique
Module 2 - Division / Functional / Equivalence Partitioning

## Preconditions
- Người dùng đã truy cập trang: https://testsheepnz.github.io/BasicCalculator.html
- Chọn Build: Prototype

## Test data
| Build | Prototype |
| First number | 5 |
| Second number | 2 |
| Operation | Divide |

## Test steps
1. Chọn Build "Prototype".
2. Nhập "5" vào trường First number và "2" vào trường Second number.
3. Chọn Operation là "Divide".
4. Bấm "Calculate".

## Expected result
Answer hiển thị chính xác "2.5". Không có thông báo lỗi.

Not Run / None
