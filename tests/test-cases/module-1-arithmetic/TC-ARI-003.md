# TC-ARI-003: Thực hiện phép cộng số nguyên âm với số nguyên dương

## Requirement ID
FR-CALC-01

## Module / Test type / Technique
Module 1 - Arithmetic / Functional / Equivalence Partitioning

## Preconditions
- Người dùng đã truy cập trang: https://testsheepnz.github.io/BasicCalculator.html
- Chọn Build: Prototype

## Test data
| Build | Prototype |
| First number | -10 |
| Second number | 30 |
| Operation | Add |

## Test steps
1. Truy cập trang web Basic Calculator
2. Chọn Build "Prototype" từ dropdown
3. Nhập "-10" vào trường First number
4. Nhập "30" vào trường Second number
5. Chọn Operation là "Add"
6. Bấm nút "Calculate"

## Expected result
Trường Answer hiển thị kết quả chính xác là "20". Không có thông báo lỗi hiển thị.
